ManaChaiLeasing Phase 2O.5.1
Pawn Transaction Time Hotfix
Version 0.3.9

ปัญหาที่แก้
- รายการรับจำนำใหม่ในหน้า "รายการเคลื่อนไหววันนี้" แสดงเวลา 00:00
- เกิดทั้งการรับจำนำทั่วไปและการนำสินค้าที่ไถ่ถอนแล้วกลับมาจำนำใหม่

สาเหตุ
- DatePicker ส่งวันที่ที่เลือกมาโดยมีเวลา 00:00
- ระบบเดิมนำค่านั้นไปเก็บเป็นเวลาของตั๋วและ Transaction รับจำนำโดยตรง

การทำงานใหม่
1. ตั๋วใหม่ยังใช้วันที่รับจำนำที่ผู้ใช้เลือกตามเดิม
2. ส่วนเวลาจะใช้เวลาจริง ณ ตอนกดบันทึก
3. Transaction รับจำนำจะใช้วันและเวลาเดียวกับตั๋วใหม่
4. ตั๋วและ Transaction เดิมที่เวลาเป็น 00:00 จะซ่อมจากเวลา CreatedAt
5. ไม่แก้ยอดเงิน สถานะ ลูกค้า สินค้า หรือประวัติทางการเงินอื่น

Version และ Database
- ยังคงเป็น 0.3.9 เพราะเป็น UAT Hotfix ของ Phase 2O.5
- เพิ่ม Data Migration 20260823000300_FixPawnTransactionTimes
- Migration ทำงานอัตโนมัติเมื่อเปิดโปรแกรมครั้งแรกหลังลง Hotfix
- ควร Backup Database ก่อนเปิดโปรแกรมครั้งแรก

UAT
1. Backup Database แล้วแตก Hotfix ทับ Project
2. dotnet clean และ dotnet build ต้องผ่าน
3. เปิดโปรแกรมและดูรายการรับจำนำเดิมที่เคยแสดง 00:00
4. ตรวจว่าเวลาเปลี่ยนเป็นเวลาจริงที่รายการนั้นถูกสร้าง
5. สร้างตั๋วรับจำนำใหม่ทั่วไป แล้วตรวจว่าเวลาไม่ใช่ 00:00
6. นำสินค้าที่ไถ่ถอนแล้วกลับมาจำนำใหม่ แล้วตรวจว่าเวลาไม่ใช่ 00:00
7. ตรวจวันที่ ยอดเงิน สถานะ และประวัติรายการเดิมว่ายังถูกต้อง
