ManaChaiLeasing Phase 2O.7.1
Customer History Access & Cursor Fix
Version 0.3.12

สิ่งที่แก้ไข

1. Cursor หลังอ่านบัตรประชาชน
- เดิม Wait Cursor ถูกครอบทั้งขั้นตอนอ่านบัตร หน้าตรวจสอบ และหน้าประวัติลูกค้า
- ทำให้หน้าประวัติแสดงวงกลมหมุนจนกว่าจะปิดหน้าต่าง
- แก้ให้ Wait Cursor แสดงเฉพาะช่วงที่โปรแกรมกำลังอ่านข้อมูลจาก Hardware
- หลังอ่านบัตรสำเร็จหรือไม่สำเร็จ Cursor จะกลับเป็นลูกศรปกติก่อนเปิดหน้าต่างถัดไป

2. เปิดประวัติและกำไรโดยไม่ต้องเสียบบัตร
- หน้า "ค้นหาลูกค้าเก่า" เพิ่มปุ่ม "ดูประวัติและกำไร"
- ค้นหาได้ด้วยชื่อ นามสกุล เลขบัตรประชาชน โทรศัพท์ หรือที่อยู่ตามเดิม
- เลือกลูกค้าแล้วกดปุ่มใหม่ เพื่อเปิดหน้าประวัติและสรุปกำไรรายลูกค้า
- ใช้ Customer ID ภายในระบบ จึงรองรับลูกค้าที่ไม่มีเลขบัตรประชาชนด้วย

3. หน้าประวัติลูกค้าใช้ได้จากทั้งสองทาง
- อ่านบัตรประชาชนแล้วพบลูกค้าเดิม
- ค้นหาลูกค้าเก่าด้วยตนเอง
- เปลี่ยนชื่อหน้าต่างเป็น "ประวัติลูกค้า"
- เปลี่ยนข้อความหัวหน้าเป็น "ข้อมูลลูกค้าและประวัติการใช้บริการ"

4. Workflow เดิมยังคงอยู่
- Double-click ลูกค้าในหน้าค้นหา ยังคงเลือกข้อมูลลูกค้าเพื่อรับจำนำใหม่
- ปุ่ม "เลือกข้อมูลลูกค้า" ยังทำงานเหมือนเดิม
- จากหน้าประวัติสามารถเลือก "ใช้ข้อมูลนี้รับจำนำใหม่" ได้
- จากหน้าประวัติสามารถเลือก "จำนำสินค้าเดิมอีกครั้ง" ได้
- ถ้าเลือกจำนำสินค้าเดิม ระบบจะนำ Draft กลับไปหน้า "รับจำนำใหม่" ตามเดิม

Version และ Database
- เปลี่ยน Release Version เป็น 0.3.12
- ไม่มี Database Migration เพิ่ม
- ไม่แก้ไขข้อมูลลูกค้า ตั๋ว หรือ Transaction

UAT

A. ตรวจ Cursor จากเครื่องอ่านบัตรจริง
1. เสียบบัตรประชาชนและกดอ่านบัตร
2. ระหว่างอ่าน Hardware สามารถเห็น Wait Cursor ได้
3. เมื่อหน้าตรวจสอบข้อมูลเปิด Cursor ต้องเป็นลูกศรปกติ
4. ไปต่อจนถึงหน้าประวัติลูกค้า Cursor ต้องเป็นลูกศรปกติ
5. ปิดหน้าประวัติและตรวจว่าหน้าหลักยังใช้ Cursor ปกติ

B. ตรวจการเปิดประวัติโดยไม่เสียบบัตร
1. ไปหน้า "รับจำนำใหม่"
2. กด "ค้นหาลูกค้าเก่า"
3. ค้นหาด้วยชื่อ โทรศัพท์ หรือข้อมูลอื่น
4. เลือกลูกค้าแล้วกด "ดูประวัติและกำไร"
5. ตรวจชื่อ ประวัติตั๋ว และกำไรว่าเป็นของลูกค้าที่เลือก
6. ตรวจลูกค้าที่ไม่มีเลขบัตรประชาชนว่าสามารถเปิดดูได้

C. Regression
1. Double-click ลูกค้า ต้องยังเลือกข้อมูลกลับไปยังฟอร์มรับจำนำใหม่
2. ปุ่ม "เลือกข้อมูลลูกค้า" ต้องทำงานตามเดิม
3. ในหน้าประวัติ กด "ใช้ข้อมูลนี้รับจำนำใหม่" ต้องกลับไปพร้อมข้อมูลลูกค้า
4. เลือกตั๋วที่ไถ่ถอนแล้วและกด "จำนำสินค้าเดิมอีกครั้ง" ต้องสร้าง Draft ได้
5. ตรวจตัวกรองกำไร ทั้งหมด วันนี้ เดือนนี้ ปีนี้ และกำหนดเอง
