ManaChaiLeasing — Phase 2P.1 Direct Purchase & Inventory
Version 0.4.0

ขอบเขต
- เพิ่มเมนู "รายการซื้อขาย" สำหรับรับซื้อสินค้าโดยตรงจากผู้ขาย (ไม่ใช่ตั๋วจำนำ)
- สถานะมี 3 สถานะเท่านั้น: รอขาย, ขายแล้ว, ยกเลิก
- Phase 2P.1 บันทึกรายการใหม่เป็นสถานะ "รอขาย"
- สถานะ "ขายแล้ว" เตรียมโครงสร้างไว้สำหรับ Phase 2P.2
- ไม่มีสถานะคืนสินค้าให้ผู้ขาย

ข้อมูลรับซื้อ
- เลขที่เอกสารรับซื้อไม่บังคับและเว้นว่างได้
- หากกรอกเลขที่เอกสาร ระบบห้ามเลขซ้ำ
- บันทึกวันที่รับซื้อ ราคารับซื้อ ช่องทางชำระ หมายเหตุ ผู้ขาย และรายละเอียดสินค้า
- หนึ่งรายการรับซื้อต่อสินค้าหนึ่งชิ้น
- ข้อมูลผู้ขายเลือกจากลูกค้าเดิม อ่านบัตรประชาชน หรือกรอกเองได้

การค้นหาและแก้ไข
- ค้นหาด้วยเลขที่เอกสาร ชื่อผู้ขาย เลขบัตร โทรศัพท์ สินค้า และ IMEI/Serial
- กรองทุกสถานะ / รอขาย / ขายแล้ว / ยกเลิก
- รายการรอขายเปิดกลับมาแก้ไขเลขที่เอกสาร วันที่ ราคา ผู้ขาย สินค้า และหมายเหตุได้
- ทุกครั้งที่แก้ไขจะบันทึกผู้ใช้ เครื่อง วันเวลา เหตุผล และรายละเอียดที่เปลี่ยนใน Audit Log
- รายการขายแล้วหรือยกเลิกเปิดดูได้แต่แก้ไขไม่ได้

การยกเลิก
- ยกเลิกได้เฉพาะสถานะรอขาย
- ต้องระบุเหตุผล
- ใช้สำหรับกรณีบันทึกผิดหรือรายการซ้ำ
- Transaction เงินจ่ายรับซื้อจะถูก Void และไม่นับในสรุปเงินสด
- รายการยกเลิกไม่สามารถนำไปขายได้

เงินสดและรายงาน
- เงินที่จ่ายรับซื้อรวมในยอดจ่ายออกของหน้าหลักและรายการวันนี้
- รายการรับซื้อแสดงในตารางความเคลื่อนไหววันนี้
- ดับเบิลคลิกรายการรับซื้อในรายการวันนี้เพื่อเปิดรายละเอียดได้
- Phase นี้ยังไม่มีการบันทึกขายหรือคำนวณกำไรจากการซื้อขาย (ทำใน Phase 2P.2)

UAT แนะนำ
1. สำรอง ManaChaiLeasing.db ก่อนเปิดเวอร์ชันใหม่ครั้งแรก
2. Build และเปิดโปรแกรม ตรวจ Version v0.4.0
3. เปิดเมนูรายการซื้อขาย แล้วบันทึกรายการโดยเว้นเลขที่รับซื้อ
4. บันทึกรายการที่มีเลขที่รับซื้อ และทดลองเลขซ้ำ
5. ทดลองค้นหาและกรองสถานะ
6. เปิดรายการรอขาย แก้ไขราคา วันที่ ผู้ขาย และสินค้า
7. ตรวจยอดจ่ายออกในหน้าหลักและรายการวันนี้
8. ยกเลิกรายการโดยไม่กรอกเหตุผล ต้องบันทึกไม่ได้
9. ยกเลิกพร้อมเหตุผล ตรวจว่ายอดจ่ายถูกตัดออกและรายการแก้ไขไม่ได้
10. ทดลองอ่านบัตรจริงและเลือกผู้ขายจากค้นหาลูกค้าเก่า
