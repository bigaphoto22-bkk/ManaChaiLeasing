ManaChaiLeasing Phase 2O.8.1
Transaction Profit Column
Version 0.3.14

สิ่งที่เพิ่ม

1. คอลัมน์กำไรในประวัติรายการ
- เพิ่มคอลัมน์ "กำไร" ในหน้า รายละเอียดตั๋วจำนำ > ประวัติรายการ
- แสดงกำไรแยกตาม Transaction แต่ละแถว

2. สูตรกำไรราย Transaction
- จำนำ: แสดง "-" เพราะเงินต้นที่จ่ายออกไม่ใช่กำไร
- ต่อดอก: แสดงจำนวนดอกเบี้ยที่รับในรายการนั้น
- ไถ่ถอน: ยอดรับไถ่ถอน - เงินต้น
- จำหน่าย: ราคาจำหน่าย - เงินต้น
- กำไรเป็นบวกแสดงสีเขียว
- ขาดทุนแสดงตัวเลขติดลบสีแดง
- เมื่อเลือกแถว ตัวเลขเปลี่ยนเป็นสีขาวเพื่อให้อ่านชัด

3. ป้องกันการนับซ้ำ
- ดอกเบี้ยจากการต่อดอกแต่ละครั้งแสดงในแถวต่อดอกของตัวเอง
- แถวไถ่ถอนแสดงเฉพาะกำไรจากรายการไถ่ถอนรอบสุดท้าย
- แถวจำหน่ายแสดงเฉพาะกำไรหรือขาดทุนจากราคาจำหน่ายเทียบเงินต้น
- คอลัมน์กำไรในหน้าค้นหาตั๋วยังคงแสดงกำไรสุทธิสะสมของตั๋วทั้งใบ

Version และ Database
- เปลี่ยน Release Version เป็น 0.3.14
- ไม่มี Database Migration เพิ่มจาก Phase 2O.8
- ยังคงใช้ Migration ของ Phase 2O.8 สำหรับการรักษาวันครบกำหนด

UAT

1. เปิดรายละเอียดตั๋วที่ยังมีเฉพาะรายการจำนำ
2. ตรวจแถวจำนำว่าคอลัมน์กำไรแสดง "-"
3. เปิดตั๋วที่เคยต่อดอก ตรวจว่ากำไรแต่ละแถวเท่ากับดอกเบี้ยของครั้งนั้น
4. เปิดตั๋วไถ่ถอนแล้ว ตรวจว่าแถวไถ่ถอนแสดงยอดรับลบเงินต้น
5. เปิดตั๋วจำหน่ายแล้ว ตรวจว่าแถวจำหน่ายแสดงราคาขายลบเงินต้น
6. ตรวจรายการจำหน่ายขาดทุนว่าแสดงค่าติดลบสีแดง
7. บวกกำไรทุกแถวด้วยตนเอง แล้วเทียบกับคอลัมน์กำไรสะสมในหน้าค้นหาตั๋ว
8. เลือกแถวในตาราง ตรวจว่าข้อความกำไรเปลี่ยนเป็นสีขาวอ่านชัด
