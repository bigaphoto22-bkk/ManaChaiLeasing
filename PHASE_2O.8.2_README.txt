สิ่งที่ปรับปรุง
- ขยายปฏิทินของช่อง "วันที่รับจำนำ" ในหน้ารับจำนำใหม่ประมาณ 1.55 เท่า
- ตัวเลขวันที่ ชื่อเดือน และปุ่มลูกศรเปลี่ยนเดือนมีขนาดใหญ่ขึ้น
- พื้นที่คลิกของแต่ละวันใหญ่ขึ้นตามปฏิทิน
- ช่องกรอกวันที่ด้านนอกยังคงขนาดเดิม เพื่อไม่ให้ฟอร์มเปลี่ยนสัดส่วน
- การเลือกวันที่ การพิมพ์วันที่ และ Keyboard Shortcut เดิมยังทำงานตามเดิม

Database

- ไม่มี Migration เพิ่ม
