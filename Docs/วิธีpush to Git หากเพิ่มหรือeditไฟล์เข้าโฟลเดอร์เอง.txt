วิธี push to Git ถ้าเพิ่มไฟล์ใหม่เข้าไปในโฟลเดอร์เอง ต้อง git add ก่อนแล้วตามด้วย git push เช่น
-ได้เพิ่มไฟล์ชื่อ Machine ID & AnyDesk.txt  เข้าไปในโฟลเดอร์ Docs

1.รันคำสั่งเพื่อดูว่ามีเฉพาะไฟล์ที่ต้องการ

git add -- "Docs/วิธีpush to Git หากเพิ่มไฟล์เข้าโฟลเดอร์เอง.txt"

git commit -m "Update Git push instructions"

git push origin main

git status


2.รันคำสั่ง pull (กรณีทำงานคนละเครื่องต้องทำก่อนทุกครั้ง)
-pull

cd C:\Dev\PawnShop-2\ManaChaiLeasing

git status
git pull --ff-only origin main
git status


3.สถานะสุดท้ายควรเป็น:
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean



4.หากแก้ไขไฟล์เดิมในโฟลเดอร์ Docs และกด Save แล้ว ให้ใช้คำสั่งนี้:

cd C:\Dev\PawnShop-2\ManaChaiLeasing

git status
git diff -- "Docs/วิธีpush to Git หากเพิ่มไฟล์เข้าโฟลเดอร์เอง.txt"

git add -- "Docs/วิธีpush to Git หากเพิ่มไฟล์เข้าโฟลเดอร์เอง.txt"
git commit -m "Update Git usage instructions"

git pull --rebase origin main
git push origin main

git status
