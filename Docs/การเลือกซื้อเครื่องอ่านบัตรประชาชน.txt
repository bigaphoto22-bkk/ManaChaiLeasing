การเลือกซื้อเครื่องอ่านบัตรประชาชน

-เป็นเครื่องอ่านบัตรแบบสัมผัส ขนาดบัตรประชาชนปกติ
-รองรับ PC/SC
-รองรับ USB CCID
-รองรับ Protocol T=0 หรือ T=1
-มี Driver สำหรับ Windows
-Windows มองเห็นใน Device Manager → Smart card readers

โปรแกรมเราเรียกผ่านระบบ Smart Card มาตรฐานของ Windows (winscard.dll) ดังนั้นเครื่องที่เข้าเงื่อนไขนี้มีโอกาสใช้งานได้โดยไม่ต้องแก้โปรแกรม

รุ่นที่ผมแนะนำ:

1.ACS ACR39U — แนะนำเป็นตัวแรก ราคาโดยทั่วไปไม่สูงและสเปกตรงกับโปรแกรม รองรับ PC/SC, CCID, Windows และ T=0/T=1 ข้อมูลจากผู้ผลิต ACS
2.ACS ACR40U — รุ่นใหม่กว่า รองรับ PC/SC, CCID, Windows และ T=0/T=1 เช่นกัน ข้อมูลจากผู้ผลิต ACS

หลีกเลี่ยง:

-เครื่องอ่าน NFC/Contactless อย่างเดียว
-เครื่องอ่านเฉพาะ SIM
-รุ่นที่ต้องใช้ SDK เฉพาะของผู้ขายและไม่รองรับ PC/SC
-รุ่นที่ไม่มี Driver Windows
-สินค้าที่ระบุเพียง “อ่านบัตรประชาชนได้” แต่ไม่บอก PC/SC หรือ CCID

คำแนะนำคือซื้อ ACS ACR39U จำนวน 1 เครื่องมาทำ Real-device UAT ก่อน ถ้าอ่านบัตรจริงครบ จึงค่อยซื้อเครื่องสำหรับลูกค้าครับ เพราะแม้สเปกตรง เรายังต้องทดสอบ Driver และบัตรประชาชนจริงกับโปรแกรม v0.3.6 อีกครั้งก่อนส่งมอบเต็มรูปแบบครับ
