ManaChaiLeasing - Phase 2H.2
Dashboard Period & Historical Overview

เมนูช่วงเวลา:
- วันนี้
- สัปดาห์นี้ (จันทร์ - วันนี้)
- เดือนนี้ (วันที่ 1 - วันนี้)
- กำหนดเอง (วันที่เริ่มต้น - วันที่สิ้นสุด)

Dashboard แบ่งเป็น:
1. สถานะ ณ วันสิ้นสุดช่วง
   - กำลังจำนำ
   - ครบกำหนด
   - เกินกำหนด

2. ความเคลื่อนไหวในช่วงที่เลือก
   - จำนำใหม่ + เงินจ่ายออก
   - ต่อดอก + เงินรับเข้า
   - ไถ่ถอน + เงินรับเข้า

3. สรุปเงินสดในช่วงที่เลือก
   - รายรับรวม
   - รายจ่ายรวม
   - เงินสดสุทธิ

Historical status:
- คำนวณจาก PawnDate + Transaction history ถึงสิ้นวันของช่วงที่เลือก
- ตั๋วที่ไถ่ถอนภายหลังยังนับเป็น Active ในวันที่ย้อนหลัง ก่อนวันที่ไถ่ถอน
- Renewal ที่เกิดก่อนหรือในวันสิ้นสุดช่วงจะถูกนำไปคำนวณ Due Date ณ วันนั้น
