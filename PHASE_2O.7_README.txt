ManaChaiLeasing Phase 2O.7
Customer Profit Summary
Version 0.3.11

แนวคิด
- หน้าภาพรวมแสดงกำไรทั้งร้าน แต่ยังไม่สามารถดูว่าลูกค้าคนหนึ่งสร้างกำไรเท่าไร
- Phase นี้เพิ่มสรุปกำไรรายลูกค้าในหน้าประวัติการใช้บริการ
- ใช้สูตรเดียวกับกำไรในหน้าภาพรวม

สิ่งที่เพิ่ม
1. แถบ "สรุปกำไรจากลูกค้ารายนี้" เหนือตารางประวัติการใช้บริการ
2. แสดงข้อมูล 4 รายการ
   - ดอกเบี้ยรับ
   - กำไรจากไถ่ถอน
   - กำไร/ขาดทุนจำหน่าย
   - กำไรรวม
3. เลือกช่วงเวลาได้จาก Dropdown
   - ทั้งหมด
   - วันนี้
   - เดือนนี้
   - ปีนี้
   - กำหนดเอง
4. ช่วงกำหนดเองเลือกวันที่เริ่มต้นและวันที่สิ้นสุด แล้วกดแสดงผล
5. กำไรติดลบแสดงเป็นสีแดง
6. เมื่อกลับจากการต่อดอก ไถ่ถอน หรือจำหน่าย ระบบคำนวณกำไรใหม่ทันที

สูตรกำไร
- ดอกเบี้ยรับ = Transaction ต่อดอกที่รับเงินจริง
- กำไรจากไถ่ถอน = ยอดไถ่ถอน - เงินต้น
- กำไร/ขาดทุนจำหน่าย = ราคาจำหน่าย - เงินต้น
- กำไรรวม = ดอกเบี้ยรับ + กำไรจากไถ่ถอน + กำไร/ขาดทุนจำหน่าย

กฎสำคัญ
- เงินต้นที่ปล่อยจำนำไม่ถือเป็นขาดทุน
- เงินต้นที่รับคืนไม่ถือเป็นกำไร
- ไม่นับ Transaction ที่ถูกยกเลิก
- คำนวณช่วงเวลาจากวันที่เกิด Transaction จริง ไม่ใช่วันที่เริ่มจำนำ
- รวมตั๋วทุกใบของลูกค้าคนเดียวกัน รวมถึงตั๋วจำนำสินค้าเดิมในรอบใหม่
- รายการจำหน่ายที่ต่ำกว่าเงินต้นแสดงผลติดลบตามจริง

Version และ Database
- เปลี่ยน Release Version เป็น 0.3.11
- ไม่มี Database Migration เพิ่ม
- ไม่แก้ไขข้อมูลลูกค้า ตั๋ว หรือ Transaction
- เป็นการอ่านและคำนวณจากข้อมูลเดิมเท่านั้น

UAT

A. ตรวจสูตรแบบง่าย
1. ใช้ลูกค้าที่มีตั๋วเงินต้น 10,000 บาท
2. ต่อดอก 500 บาท ตรวจดอกเบี้ยรับและกำไรรวมเพิ่ม 500 บาท
3. ไถ่ถอน 10,500 บาท ตรวจกำไรจากไถ่ถอนเพิ่ม 500 บาท
4. กำไรรวมของลูกค้าควรเป็น 1,000 บาท

B. ตรวจการจำหน่าย
1. ใช้ตั๋วเงินต้น 10,000 บาทที่เกินกำหนด
2. จำหน่าย 8,000 บาท
3. ตรวจว่ากำไร/ขาดทุนจำหน่ายแสดง -2,000 บาทเป็นสีแดง
4. ตรวจว่ากำไรรวมรวมค่าติดลบนี้ตามจริง

C. ตรวจช่วงเวลา
1. เลือกทั้งหมด ตรวจว่ารวม Transaction ทุกช่วงเวลา
2. เลือกวันนี้ ตรวจว่าแสดงเฉพาะกำไรที่เกิดวันนี้
3. เลือกเดือนนี้และปีนี้ ตรวจยอดตามช่วง
4. เลือกกำหนดเอง ตั้งวันที่เริ่มต้นและสิ้นสุด แล้วกดแสดงผล
5. ทดลองวันที่เริ่มต้นมากกว่าวันที่สิ้นสุด ระบบต้องแจ้งเตือน

D. ตรวจความถูกต้องอื่น
1. ตรวจว่าตั๋วของลูกค้าคนอื่นไม่ถูกรวม
2. ตรวจว่าเงินต้นรับจำนำไม่ถูกนับเป็นกำไร
3. ตรวจ Transaction ที่ยกเลิกว่าไม่ถูกนับ
4. เปิดรายละเอียดแล้วต่อดอก/ไถ่ถอน/จำหน่าย กลับมาหน้าประวัติแล้วยอดต้องเปลี่ยนทันที
5. ตรวจปุ่มจำนำสินค้าเดิม ตารางประวัติ และ ESC ว่ายังทำงานตามเดิม
