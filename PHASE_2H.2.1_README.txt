เป้าหมาย:
- ลดความรกของหน้า Home Dashboard
- ไม่เปลี่ยน logic การคำนวณของ Phase 2H.2
- คงตัวเลือกช่วงเวลา: วันนี้ / สัปดาห์นี้ / เดือนนี้ / กำหนดเอง

การปรับ UI:
1. ตัดชื่อร้านและคำว่า "ภาพรวมกิจการ" ที่ซ้ำกับ Sidebar ออกจาก Hero card
2. Header เหลือ "ภาพรวม" + ช่วงวันที่ + ปุ่มรีเฟรช
3. สถานะ กำลังจำนำ / ครบกำหนด / เกินกำหนด รวมเป็นแถบ compact แถวเดียว
4. คงการ์ดหลักเพียง 3 ใบ: จำนำใหม่ / ต่อดอก / ไถ่ถอน
5. รายรับรวม / รายจ่ายรวม / เงินสดสุทธิ รวมเป็นแถวเดียว
6. เงินสดสุทธิเด่นกว่าสองตัวแรก
7. ตัดข้อความอธิบายย่อยที่ไม่จำเป็น
8. ตัดข้อความ Phase 2H.2 ออกจากหน้าจอใช้งานจริง
