Thai ID Real-device UAT UX Polish
Version 0.3.10

ผล Real-device UAT ที่ยืนยันแล้ว
- Windows ตรวจพบ Microsoft Usbccid Smartcard Reader (WUDF)
- โปรแกรมอ่านข้อมูลจากบัตรจริงได้ถูกต้อง
- ชื่อ นามสกุล เลขบัตร อายุ และที่อยู่ถูกเติมลงฟอร์ม
- พบลูกค้าเดิมและเปิดประวัติการใช้บริการได้

สิ่งที่ปรับปรุง

1. หน้าตรวจสอบลูกค้าเดิมกับข้อมูลจากบัตร
- เปลี่ยนหัวข้อเป็น "พบข้อมูลลูกค้าเก่า"
- แสดงข้อความสั้นว่าเป็นลูกค้าเก่าและมีข้อมูลอยู่ในระบบแล้ว
- หากข้อมูลตรงกัน หน้าต่างจะย่อลงและแสดงเฉพาะคำแนะนำให้ใช้ข้อมูลเดิม
- ซ่อนคำอธิบาย ตารางเปรียบเทียบ และปุ่มที่ไม่จำเป็นเมื่อไม่มีข้อมูลต่างกัน
- หากข้อมูลจากบัตรต่างจากระบบ จะแสดงเฉพาะรายการที่ต่างเพื่อให้เลือก
- ไม่แสดงเลขบัตรประชาชนซ้ำในหัวข้อ ลดข้อมูลบนหน้าจอและลดความเสี่ยงด้านความเป็นส่วนตัว

2. ปุ่ม "จำนำสินค้าเดิมอีกครั้ง"
- คงกฎเดิม: ใช้ได้เฉพาะตั๋วสถานะไถ่ถอนแล้ว
- ตั๋วกำลังจำนำกดไม่ได้ เพราะสินค้ายังอยู่ในตั๋วปัจจุบัน
- ตั๋วเดิมที่เคยใช้สร้างตั๋วใหม่แล้วกดซ้ำไม่ได้
- เพิ่มข้อความใต้ตารางและ Tooltip อธิบายสาเหตุที่ปุ่มกดไม่ได้

3. ตารางประวัติการใช้บริการ
- จัดข้อความทุกคอลัมน์ให้อยู่กึ่งกลางแนวตั้ง
- จัดหัวคอลัมน์ให้อยู่กึ่งกลางแนวตั้ง
- เมื่อเลือกแถว พื้นหลังเป็นสีน้ำเงินและข้อความทุกช่องเป็นสีขาว
- แก้ข้อความสถานะไม่ให้กลืนกับพื้นหลังสีน้ำเงิน
- ข้อความสินค้าที่ยาวจะแสดงแบบตัดท้ายโดยไม่เพิ่มความสูงของแถว

4. ตารางประวัติรายการในหน้ารายละเอียดตั๋ว
- จัดข้อความและหัวคอลัมน์ให้อยู่กึ่งกลางแนวตั้ง
- เลือกแบบเต็มแถวเพื่อให้รูปแบบสม่ำเสมอ
- เมื่อเลือกแถว ข้อความรายการและคอลัมน์อื่นเป็นสีขาวบนพื้นหลังสีน้ำเงิน

Version และ Database
- เปลี่ยน Release Version เป็น 0.3.10
- ไม่มี Database Migration เพิ่ม
- ไม่เปลี่ยนข้อมูลลูกค้า ตั๋ว หรือ Transaction
- ไม่เปลี่ยนกฎจำนำสินค้าเดิม

UAT

A. ลูกค้าเก่าและข้อมูลตรงกัน
1. อ่านบัตรลูกค้าเก่าที่ข้อมูลตรงกับระบบ
2. กดเติมข้อมูลลงฟอร์ม
3. ตรวจว่าหน้าต่างแสดง "พบข้อมูลลูกค้าเก่า"
4. ตรวจว่าข้อความสั้น อ่านง่าย และไม่มีตารางเปรียบเทียบที่ว่าง
5. กดใช้ข้อมูลเดิม ต้องเปิดประวัติการใช้บริการ

B. ลูกค้าเก่าและข้อมูลต่างกัน
1. เตรียมลูกค้าเดิมที่ระบบยังไม่มีที่อยู่ หรือมีข้อมูลต่างจากบัตร
2. อ่านบัตรและกดเติมข้อมูลลงฟอร์ม
3. ตรวจว่าแสดงเฉพาะช่องที่ต่าง
4. เลือกรายการจากบัตรและนำไปใช้
5. ตรวจว่าฟอร์มเปลี่ยนเฉพาะรายการที่เลือก

C. ประวัติการใช้บริการ
1. ตรวจว่าข้อความทุกแถวอยู่กึ่งกลางแนวตั้ง
2. คลิกแถว ตรวจว่าข้อความสถานะและทุกคอลัมน์เป็นสีขาวอ่านชัด
3. เลือกตั๋วกำลังจำนำ ตรวจว่าปุ่มจำนำสินค้าเดิมกดไม่ได้และมีข้อความอธิบาย
4. เลือกตั๋วไถ่ถอนแล้วที่ยังไม่เคยใช้สร้างตั๋วใหม่ ตรวจว่าปุ่มกดได้
5. เลือกตั๋วไถ่ถอนแล้วที่สร้างตั๋วใหม่แล้ว ตรวจว่าปุ่มกดไม่ได้และมีข้อความอธิบาย

D. รายละเอียดตั๋ว
1. เปิดตั๋วที่มีประวัติรายการ
2. ตรวจว่าข้อความในตารางอยู่กึ่งกลางแนวตั้ง
3. คลิกแถว ตรวจว่าข้อความทุกคอลัมน์อ่านชัดบนพื้นหลังสีน้ำเงิน
4. ตรวจว่าปุ่ม ESC และปุ่มปิดยังทำงานตามเดิม
