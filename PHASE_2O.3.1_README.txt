ManaChaiLeasing Phase 2O.3.1
UAT Hotfix
Version 0.3.7

แก้ไขจากผล UAT
1. สรุปรายละเอียดสินค้าอัปเดตทันทีเมื่อเลือกค่าใน ComboBox ด้วยเมาส์
   รวมถึงยังรองรับการเลือกด้วยแป้นพิมพ์และการพิมพ์ค่าเอง
2. รายการเคลื่อนไหววันนี้สามารถดับเบิลคลิกเพื่อเปิดรายละเอียดตั๋วได้
3. เมื่อกลับจากรายละเอียดตั๋ว รายการวันนี้จะ Refresh อัตโนมัติ
4. หน้าต่อดอกสำเร็จปรับความสูงตามเนื้อหา เพื่อไม่ให้ช่องทางการชำระเงินตกขอบ

Version
- ยังคงเป็น 0.3.7 เพราะเป็นการแก้ผล UAT ของ Phase 2O.3 ก่อน Commit

Database
- ไม่มีการเปลี่ยนโครงสร้างฐานข้อมูล
- ไม่ต้องทำ Migration และไม่ต้องลบฐานข้อมูล

UAT
1. ในหน้ารับจำนำ เลือกสีด้วยเมาส์ ตรวจว่าสรุปอัตโนมัติเปลี่ยนเป็นสีใหม่ทันที
2. ทดลองเลือกยี่ห้อ รุ่น ความจุ และสีด้วยปุ่มลูกศร ตรวจว่าสรุปเปลี่ยนถูกต้อง
3. เปิดหน้ารายการวันนี้ แล้วดับเบิลคลิกแต่ละรายการ ตรวจว่าเปิดตั๋วที่ถูกต้อง
4. ปิดหน้ารายละเอียด ตรวจว่ากลับมาหน้ารายการวันนี้ได้ตามปกติ
5. ทำรายการต่อดอกโดยเลือกช่องทางชำระเงิน
6. ตรวจหน้าต่อดอกสำเร็จว่ามองเห็นบรรทัดช่องทางและค่าที่เลือกครบถ้วน

ขอบเขต
- ระบบแก้ไขข้อมูลตั๋วจำนำจะทำแยกใน Phase 2O.4
- ช่องข้อมูลทางการเงินและประวัติรายการจะไม่เปิดให้แก้ตรง ๆ
