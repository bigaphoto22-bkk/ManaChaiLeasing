ManaChaiLeasing — Phase 2P.2 Direct Purchase Sale & Profit
Version 0.4.3

ขอบเขต
- เพิ่ม Workflow ขายสินค้าที่ร้านรับซื้อโดยตรง
- ขายได้เฉพาะรายการสถานะ "รอขาย"
- บันทึกวันที่ขาย ราคาขาย ช่องทางรับเงิน และหมายเหตุ
- เมื่อยืนยันแล้ว สถานะเปลี่ยนเป็น "ขายแล้ว" และข้อมูลรับซื้อเป็นแบบอ่านอย่างเดียว

กำไร / ขาดทุน
- สูตร: ราคาขาย - ราคารับซื้อ
- กำไรแสดงสีเขียว และขาดทุนแสดงสีแดง
- ตารางรายการซื้อขายเพิ่มวันที่ขาย ราคาขาย และกำไร
- หน้ารายละเอียดรายการขายแล้วแสดงวันที่ขาย ราคารับซื้อ ราคาขาย กำไร ช่องทางรับเงิน และหมายเหตุ

Transaction และ Audit
- สร้าง DirectPurchaseTransaction ชนิด Sale / Income ตามวันที่ขายจริง
- ป้องกันการบันทึกขายซ้ำและป้องกันวันที่ขายก่อนวันที่รับซื้อ
- Audit Log บันทึกผู้ใช้ เครื่อง วันเวลา สถานะ ราคาขาย และกำไร/ขาดทุน
- เรียก Auto Backup หลังบันทึกขายสำเร็จ

หน้าหลักและรายการวันนี้
- รายรับจากการขายสินค้าที่รับซื้อรวมในยอดรับเข้าและยอดสุทธิ
- กำไร/ขาดทุนจากการซื้อขายรวมในกำไรหน้าหลัก
- การ์ดขาย/จำหน่ายแยกจำนวนจำนำหลุดและซื้อขาย
- รายการวันนี้แสดง "ขายสินค้า" แยกจาก "รับซื้อ" และดับเบิลคลิกเปิดรายละเอียดได้

ฐานข้อมูล
- ไม่มี Migration เพิ่ม
- ใช้ตารางและ Transaction structure จาก Phase 2P.1

UAT แนะนำ
1. Build และเปิดโปรแกรม ตรวจ Version v0.4.3
2. เปิดรายการซื้อขาย เลือกรายการสถานะรอขาย แล้วกดบันทึกขาย
3. ตรวจปฏิทินใหญ่ และทดลองเลือกวันที่ก่อนวันรับซื้อ ต้องเลือก/บันทึกไม่ได้
4. กรอกราคาขายมากกว่าราคารับซื้อ ตรวจว่ากำไรเป็นสีเขียว
5. กรอกราคาขายต่ำกว่าราคารับซื้อ ตรวจว่าขาดทุนเป็นสีแดงและไม่ถูกบังคับเป็นศูนย์
6. ยืนยันขาย ตรวจสถานะเปลี่ยนเป็นขายแล้ว และตารางแสดงวันที่ขาย ราคาขาย กำไร
7. เปิดรายละเอียดรายการขายแล้ว ตรวจข้อมูลการขายและตรวจว่าแก้ไขข้อมูลรับซื้อไม่ได้
8. ทดลองกดบันทึกขายรายการเดิมอีกครั้ง ต้องระบบไม่อนุญาต
9. ตรวจรายการวันนี้ว่ามีรายการขายสินค้า ยอดรับเข้า และยอดสุทธิถูกต้อง
10. ตรวจหน้าหลักช่วงวันนี้/สัปดาห์นี้/เดือนนี้/กำหนดเอง ว่ารายรับและกำไรรวมถูกต้อง
11. ตรวจรายการรับซื้อใหม่ แก้ไข และยกเลิก ว่ายังทำงานเหมือนเดิม
