ManaChaiLeasing Phase 2O.3
Thai ID Customer Service History
Version 0.3.7

สิ่งที่เพิ่ม
1. เมื่ออ่านบัตรประชาชนและพบเลขบัตรตรงกับลูกค้าเดิม โปรแกรมจะแสดงหน้าประวัติอัตโนมัติ
2. แสดงข้อมูลลูกค้า: ชื่อ เลขบัตร โทรศัพท์ และวันที่ใช้บริการล่าสุด
3. แสดงสรุปจำนวนตั๋ว: กำลังจำนำ ครบกำหนดวันนี้ เกินกำหนด ไถ่ถอนแล้ว และจำหน่ายแล้ว
4. แสดงประวัติตั๋วทั้งหมด พร้อมวันที่ เลขตั๋ว สินค้า เงินต้น วันครบกำหนด สถานะ และการเคลื่อนไหวล่าสุด
5. แจ้งเตือนด้วยสี โดยให้ความสำคัญกับตั๋วเกินกำหนดก่อน
6. ดับเบิลคลิกหรือเลือกตั๋วแล้วกด "เปิดตั๋วที่เลือก" เพื่อดูรายละเอียด
7. เมื่อกลับจากหน้ารายละเอียด ประวัติจะ Refresh เพื่อแสดงผลล่าสุด
8. กด "ใช้ข้อมูลนี้รับจำนำใหม่" เพื่อกลับไปทำรายการด้วยข้อมูลลูกค้าเดิม

ฐานข้อมูล
- ไม่มีการเพิ่มตารางหรือคอลัมน์
- ไม่ต้องลบฐานข้อมูลและไม่ต้องทำ Database Migration
- ใช้ข้อมูล Customer, PawnTicket และ PawnTransaction ที่มีอยู่แล้ว

UAT แนะนำ
1. เตรียมลูกค้าที่มีเลขบัตรประชาชนและมีตั๋วอย่างน้อย 1 ตั๋ว
2. อ่านบัตรเดิมอีกครั้ง หรือใช้ปุ่ม DEV MOCK โดยกรอกเลขบัตรเดิมก่อนกด
3. ในหน้าตรวจข้อมูลลูกค้าเดิม ให้เลือกใช้ข้อมูลเดิมเมื่อทดสอบด้วย DEV MOCK
4. ตรวจว่าหน้าประวัติเปิดอัตโนมัติและข้อมูลลูกค้าถูกต้อง
5. ตรวจจำนวนตั๋วแต่ละสถานะกับข้อมูลจริง
6. เลือกตั๋วแล้วกดเปิด หรือดับเบิลคลิก ตรวจว่าหน้ารายละเอียดตั๋วถูกต้อง
7. ปิดหน้ารายละเอียดแล้วตรวจว่าประวัติ Refresh
8. กดใช้ข้อมูลนี้รับจำนำใหม่ ตรวจว่ากลับมาที่ฟอร์มพร้อมข้อมูลลูกค้าเดิม

หมายเหตุ DEV MOCK
- ชื่อและที่อยู่จาก Mock เป็นข้อมูลทดสอบ
- เมื่อพบลูกค้าเดิม ให้เลือก "ใช้ข้อมูลเดิม" เพื่อไม่ให้ข้อมูลทดสอบแทนข้อมูลจริง
- ห้ามบันทึกข้อมูล Mock ลงฐานข้อมูลลูกค้าจริง
