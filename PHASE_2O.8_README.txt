สิ่งที่เพิ่ม

1. คอลัมน์กำไรในหน้าค้นหาตั๋ว
- เพิ่มคอลัมน์ "กำไร" ในรายการตั๋วทุกสถานะ
- ตั๋วที่ยังไม่มีกำไรแสดง "-"
- กำไรเป็นบวกแสดงสีเขียว
- ขาดทุนสุทธิแสดงตัวเลขติดลบสีแดง
- เมื่อเลือกแถว ตัวเลขเปลี่ยนเป็นสีขาวเพื่อให้อ่านชัด

2. สูตรกำไรรายตั๋ว
- ต่อดอก: รวมดอกเบี้ยที่รับจริงของตั๋วใบนั้น
- ไถ่ถอน: ดอกเบี้ยที่รับก่อนหน้า + ส่วนเกินเงินต้นจากรายการไถ่ถอน
- จำหน่าย: ดอกเบี้ยที่รับก่อนหน้า + ราคาจำหน่าย - เงินต้น
- แสดงเป็นกำไร/ขาดทุนสุทธิสะสมของตั๋วแต่ละใบ
- ไม่รวมเงินต้นที่ร้านจ่ายออกตอนรับจำนำ

3. แก้เลขตั๋ว
- หน้า "รายละเอียดตั๋ว" > "แก้ไขข้อมูล" สามารถแก้เลขตั๋วได้
- ตัดช่องว่างหัวท้ายก่อนบันทึก
- ไม่อนุญาตให้เลขตั๋วซ้ำกับตั๋วอื่น โดยไม่แยกตัวพิมพ์เล็ก/ใหญ่
- จำกัดความยาวไม่เกิน 50 ตัวอักษร

4. แก้วันที่จำนำ
- หน้า "รายละเอียดตั๋ว" > "แก้ไขข้อมูล" สามารถแก้วันที่จำนำได้
- ไม่อนุญาตวันที่ในอนาคต
- ไม่อนุญาตวันที่จำนำที่อยู่หลังรายการต่อดอก ไถ่ถอน หรือจำหน่ายที่มีอยู่แล้ว
- ปรับวันที่ของ Transaction จำนำรายการแรกให้ตรงกัน โดยรักษาเวลาเดิมไว้

5. กติกาวันครบกำหนด
- ตั๋วที่ยังไม่เคยต่อดอก: คำนวณวันครบกำหนดใหม่จากวันที่จำนำที่แก้ไข
- ตั๋วที่เคยต่อดอก: รักษาวันครบกำหนดล่าสุดไว้
- การต่อดอกครั้งถัดไปจะเพิ่มรอบต่อจากวันครบกำหนดที่รักษาไว้
- ใช้สูตรเดียวกันในหน้าค้นหา รายละเอียด ประวัติลูกค้า ต่อดอก ไถ่ถอน จำหน่าย และ Dashboard

6. Audit Log
- บันทึกเลขตั๋วเดิมและเลขตั๋วใหม่
- บันทึกวันที่จำนำเดิมและวันที่จำนำใหม่
- เก็บผู้แก้ไข เครื่องที่แก้ เวลา เหตุผล และค่าก่อน–หลังตามระบบเดิม

UAT

A. คอลัมน์กำไร
1. เปิดหน้าค้นหาตั๋วและตรวจว่ามีคอลัมน์ "กำไร"
2. ตั๋วกำลังจำนำที่ยังไม่เคยต่อดอกต้องแสดง "-"
3. ตั๋วที่ต่อดอกแล้วต้องแสดงผลรวมดอกเบี้ยที่รับจริง
4. ตั๋วไถ่ถอนแล้วต้องแสดงดอกเบี้ยทั้งหมดรวมดอกเบี้ยรอบไถ่ถอน
5. ตั๋วจำหน่ายแล้วต้องแสดงดอกเบี้ยเดิม + ราคาขาย - เงินต้น
6. ตรวจรายการขาดทุนว่าแสดงค่าติดลบสีแดง

B. แก้เลขตั๋ว
1. เปิดรายละเอียดตั๋ว > แก้ไขข้อมูล
2. เปลี่ยนเลขตั๋วและบันทึก
3. ตรวจเลขใหม่ในหน้ารายละเอียด หน้าค้นหา และประวัติลูกค้า
4. ทดลองใช้เลขซ้ำกับตั๋วอื่น ต้องไม่อนุญาตให้บันทึก
5. ตรวจ Audit Log ว่าแสดงเลขเดิมและเลขใหม่

C. แก้วันที่จำนำ — ยังไม่เคยต่อดอก
1. จดวันครบกำหนดเดิม
2. เปลี่ยนวันที่จำนำและบันทึก
3. ตรวจว่าวันครบกำหนดเลื่อนตามวันที่ใหม่
4. ตรวจ Transaction จำนำรายการแรกว่าเป็นวันที่ใหม่และเวลาเดิม
5. ตรวจ Audit Log

D. แก้วันที่จำนำ — เคยต่อดอกแล้ว
1. จดวันครบกำหนดล่าสุดก่อนแก้
2. เปลี่ยนวันที่จำนำและบันทึก
3. ตรวจว่าวันครบกำหนดล่าสุดไม่เปลี่ยน
4. ทดลองต่อดอกอีกครั้ง ต้องเพิ่มวันจากวันครบกำหนดเดิมหนึ่งรอบ

E. Validation และ Regression
1. ทดลองวันที่อนาคต ต้องไม่อนุญาต
2. ทดลองวันที่หลังรายการต่อดอก/ไถ่ถอน/จำหน่าย ต้องไม่อนุญาต
3. ตรวจต่อดอก ไถ่ถอน และจำหน่ายว่ายังคำนวณวันครบกำหนดถูกต้อง
4. ตรวจ Dashboard และประวัติลูกค้าว่าเปิดได้ตามปกติ
5. ปิดและเปิดโปรแกรมใหม่ ตรวจว่าข้อมูลที่แก้ไขยังอยู่ครบ
