ManaChaiLeasing — Phase 2P.2.2 Direct Purchase Action UX
Version 0.4.5

ขอบเขต
- แก้สีข้อความกำไร/ขาดทุนในแถวที่ถูกเลือก
- ลดความสับสนของปุ่มขายและปุ่มแก้ไขในหน้ารายการซื้อขาย
- ใช้ปุ่มแก้ไขเพียงปุ่มเดียวและเปลี่ยนหน้าที่ตามสถานะรายการ

สีข้อความในตาราง
- แถวปกติ: กำไรเป็นสีเขียว ขาดทุนเป็นสีแดง
- เมื่อเลือกแถว: กำไร/ขาดทุนเปลี่ยนเป็นสีขาว เพื่อให้ตัดกับพื้นหลังสีน้ำเงิน
- เมื่อยกเลิกการเลือก: สีจะกลับเป็นเขียวหรือแดงตามค่าเดิม

ปุ่มตามสถานะ
- รอขาย: แสดง "ยกเลิกรายการ", "ขายสินค้า" และ "แก้ไขข้อมูลรับซื้อ"
- ขายแล้ว: ซ่อนปุ่มยกเลิกและขาย แสดง "แก้ไขข้อมูลการขาย" เพียงปุ่มเดียว
- ยกเลิก: ซ่อนปุ่มยกเลิกและขาย แสดง "ดูรายละเอียด" แบบอ่านอย่างเดียว
- ยังไม่เลือกแถว: ปุ่มดำเนินการถูก Disable เพื่อป้องกันการกดผิดรายการ
- ดับเบิลคลิกแถวยังคงเปิดรายละเอียดเต็มเหมือนเดิม

กฎการแก้ไข
- สถานะรอขายแก้ได้เฉพาะข้อมูลรับซื้อ
- สถานะขายแล้วแก้ได้เฉพาะข้อมูลการขาย และย้อนกลับไปแก้ข้อมูลรับซื้อไม่ได้
- สถานะยกเลิกดูได้อย่างเดียว

ฐานข้อมูล
- ไม่มี Migration เพิ่ม
- ไม่เปลี่ยนข้อมูลหรือสูตรคำนวณจาก Phase 2P.2.1

UAT แนะนำ
1. Build และเปิดโปรแกรม ตรวจ Version v0.4.5
2. เลือกแถวขายแล้ว ตรวจว่ากำไร/ขาดทุนอ่านชัดเป็นสีขาวบนพื้นน้ำเงิน
3. ยกเลิกการเลือกหรือเลือกแถวอื่น ตรวจว่าสีกลับเป็นเขียว/แดงตามปกติ
4. เลือกรายการรอขาย ตรวจว่ามีปุ่มยกเลิก ขายสินค้า และแก้ไขข้อมูลรับซื้อ
5. กดแก้ไขข้อมูลรับซื้อ ตรวจว่าแก้ข้อมูลรับซื้อได้
6. เลือกรายการขายแล้ว ตรวจว่าเหลือปุ่มแก้ไขข้อมูลการขายและไม่มีปุ่มยกเลิก/ขาย
7. กดแก้ไขข้อมูลการขาย ตรวจว่าแก้ได้เฉพาะวันที่ ราคา ช่องทาง และหมายเหตุการขาย
8. เลือกรายการยกเลิก ตรวจว่าเหลือปุ่มดูรายละเอียดและข้อมูลแก้ไม่ได้
9. ไม่เลือกแถว ตรวจว่าปุ่มดำเนินการกดไม่ได้
10. ดับเบิลคลิกแต่ละสถานะ ตรวจว่ายังเปิดรายละเอียดได้
