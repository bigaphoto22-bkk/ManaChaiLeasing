Version 0.3.8

ปัญหาที่แก้
- แก้ข้อมูลแยก เช่น ความจุจาก 256 GB เป็น 512 GB แล้ว
  แต่ช่องรายละเอียดสินค้าสรุปยังคงแสดงค่าเดิม

การทำงานใหม่
1. เมื่อเปิดหน้าแก้ไข ระบบจะสร้างรายละเอียดสินค้าสรุปจากข้อมูลแยกปัจจุบัน
2. เมื่อแก้ประเภทสินค้า ยี่ห้อ รุ่น ความจุ สี IMEI/Serial อุปกรณ์ สภาพ สเปก หรือรายละเอียดอื่น
   ช่องรายละเอียดสินค้าสรุปจะเปลี่ยนตามทันที
3. ใช้หลักการสร้างสรุปเดียวกับหน้ารับจำนำใหม่
4. หลังกรอกข้อมูลด้านบนเสร็จ ผู้ใช้ยังสามารถแก้ข้อความสรุปด้วยมือได้
5. เมื่อบันทึก Audit Log จะบันทึกทั้งช่องที่แก้และรายละเอียดสินค้าสรุปที่เปลี่ยนตาม

Version และ Database
- ยังคงเป็น 0.3.8 เพราะเป็น UAT Hotfix ของ Phase 2O.4
- ไม่มี Migration เพิ่มจาก Phase 2O.4
- ไม่กระทบข้อมูลทางการเงินหรือประวัติรายการ

UAT
1. เปิดตั๋วที่ข้อมูลความจุและข้อความสรุปไม่ตรงกัน
2. กดแก้ไขข้อมูล
3. ตรวจว่ารายละเอียดสินค้าสรุปถูกสร้างจากข้อมูลแยกปัจจุบัน
4. เปลี่ยนความจุเป็นค่าอื่น ตรวจว่าข้อความสรุปเปลี่ยนทันที
5. เปลี่ยนสี รุ่น หรือยี่ห้อ ตรวจว่าข้อความสรุปเปลี่ยนตาม
6. ระบุเหตุผลและบันทึก
7. ตรวจหน้ารายละเอียดว่าส่วนข้อมูลแยกและรายละเอียดสินค้าสรุปตรงกัน
8. ตรวจ Audit Log ว่าแสดงค่าก่อน–หลังครบ
