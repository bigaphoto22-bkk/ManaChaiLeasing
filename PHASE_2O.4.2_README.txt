ManaChaiLeasing Phase 2O.4.2
Optional Edit Reason Hotfix
Version 0.3.8

การเปลี่ยนแปลง
1. เหตุผลการแก้ไขเปลี่ยนเป็นข้อมูลไม่บังคับ
2. ผู้ใช้สามารถบันทึกการแก้ไขโดยเว้นช่องเหตุผลว่างได้
3. หากเว้นว่าง Audit Log จะแสดง "เหตุผล: ไม่ได้ระบุ"
4. หากกรอกเหตุผล ระบบยังบันทึกและแสดงข้อความตามที่กรอกตามปกติ

Version และ Database
- ยังคงเป็น 0.3.8 เพราะเป็น UAT Hotfix ของ Phase 2O.4
- ไม่มี Migration เพิ่ม
- ตาราง Audit Log ยังคงเก็บข้อความเหตุผลแบบไม่เป็นค่าว่าง เพื่อให้ข้อมูลอ่านได้เสมอ

UAT
1. เปิดตั๋วและกดแก้ไขข้อมูล
2. แก้ข้อมูลอย่างน้อย 1 ช่อง โดยเว้นเหตุผลว่าง
3. บันทึก ต้องสำเร็จ
4. ตรวจ Audit Log ต้องแสดง "เหตุผล: ไม่ได้ระบุ"
5. แก้อีกครั้งและกรอกเหตุผล
6. ตรวจ Audit Log ต้องแสดงเหตุผลที่กรอก
7. ทดลองไม่เปลี่ยนข้อมูลใด ๆ ระบบยังต้องปฏิเสธการบันทึกตามเดิม
