ManaChaiLeasing Phase 2O.5
Re-pawn Redeemed Item
Version 0.3.9

แนวคิด
- ไม่เปิดตั๋วเก่ากลับมาใช้และไม่เปลี่ยนเลขตั๋วเดิม
- ใช้ตั๋วที่ไถ่ถอนแล้วเป็นต้นแบบสำหรับสร้างตั๋วจำนำใหม่
- ตั๋วเดิม สถานะเดิม และประวัติรับ–จ่ายเดิมยังคงอยู่ครบ

สิ่งที่เพิ่ม
1. ปุ่ม "จำนำสินค้าเดิมอีกครั้ง" ในหน้ารายละเอียดตั๋ว
2. ปุ่มเดียวกันในหน้าประวัติลูกค้าจากบัตรประชาชน
3. ปุ่มเปิดใช้งานเฉพาะตั๋วสถานะไถ่ถอนแล้วและยังไม่เคยถูกใช้สร้างตั๋วใหม่
4. คัดลอกข้อมูลลูกค้าปัจจุบันและข้อมูลสินค้าเดิมเข้าหน้ารับจำนำใหม่
5. แสดงแถบสีเขียวระบุตั๋วต้นทางและเตือนให้ตรวจสภาพ อุปกรณ์ และ IMEI / Serial
6. บังคับให้กรอกเลขตั๋วใหม่ วันที่ใหม่ และยอดเงินจำนำใหม่
7. ใช้อัตราดอกเบี้ยและจำนวนวันปัจจุบันจากหน้า Settings เมื่อบันทึกตั๋วใหม่
8. เชื่อมตั๋วใหม่กับตั๋วต้นทาง และแสดงความสัมพันธ์ในหน้ารายละเอียด
9. ในประวัติลูกค้า ตั๋วเดิมจะแสดง "ไถ่ถอนแล้ว • จำนำใหม่แล้ว"

ข้อมูลที่คัดลอก
- ลูกค้าคนเดิม: ชื่อ นามสกุล เลขบัตร อายุ โทรศัพท์ และที่อยู่
- ประเภทหลัก ประเภทสินค้า ยี่ห้อ รุ่น ความจุ สี
- IMEI / Serial อุปกรณ์ สภาพ สเปก และรายละเอียดอื่น

ข้อมูลที่ไม่คัดลอก
- เลขตั๋วเดิม
- วันที่รับจำนำเดิม
- เงินต้นเดิม
- อัตราดอกเบี้ยและรอบดอกเบี้ยเดิม
- หมายเหตุตั๋วเดิม
- Transaction ต่อดอก ไถ่ถอน และรายการรับ–จ่ายเดิมทั้งหมด

กฎป้องกัน
1. ใช้ได้เฉพาะตั๋ว Redeemed
2. ตั๋ว Active, Sold และ Closed ใช้เป็นต้นทางไม่ได้
3. ตั๋วเดิมหนึ่งใบสร้างตั๋วใหม่ได้เพียงหนึ่งใบ
4. หากนำสินค้ากลับมาจำนำรอบถัดไป ต้องเริ่มจากตั๋วล่าสุดที่ไถ่ถอนแล้ว
5. หาก IMEI / Serial เดียวกันยังอยู่ในตั๋ว Active ระบบจะไม่อนุญาตให้บันทึก
6. ลูกค้าในตั๋วใหม่ต้องเป็นเจ้าของเดียวกับตั๋วต้นทาง
7. เลขตั๋วใหม่ต้องไม่ซ้ำตามกฎเดิม

Database Migration
- เพิ่ม SourcePawnTicketId แบบ Nullable ในตาราง PawnTickets
- เพิ่ม Unique Index เพื่อป้องกันการใช้ตั๋วต้นทางซ้ำ
- โปรแกรม Migration อัตโนมัติเมื่อเปิดเวอร์ชัน 0.3.9 ครั้งแรก
- ไม่ลบหรือเปลี่ยนข้อมูลตั๋วและ Transaction เดิม
- ควร Backup ฐานข้อมูลก่อนเปิดเวอร์ชันนี้ครั้งแรก

UAT เส้นทางหน้าค้นหารายการ
1. เตรียมตั๋วสถานะไถ่ถอนแล้ว 1 ใบ
2. เปิดรายละเอียด ตรวจว่าปุ่มจำนำสินค้าเดิมอีกครั้งกดได้
3. กดปุ่มและยืนยัน ตรวจว่ากลับหน้ารับจำนำใหม่
4. ตรวจแถบสีเขียวและเลขตั๋วต้นทาง
5. ตรวจข้อมูลลูกค้าและสินค้าว่าคัดลอกครบ
6. ตรวจว่าเลขตั๋ว ยอดเงิน และหมายเหตุว่าง และวันที่เป็นวันนี้
7. ปรับสภาพ / อุปกรณ์ / IMEI ตามสินค้าจริง
8. กรอกเลขตั๋วใหม่และยอดเงินใหม่ แล้วบันทึก
9. เปิดตั๋วใหม่ ตรวจว่าระบุว่าถูกสร้างจากตั๋วเดิม
10. เปิดตั๋วเดิม ตรวจว่าระบุเลขตั๋วใหม่และปุ่มถูกปิด

UAT เส้นทางประวัติลูกค้าจากบัตร
1. เปิดประวัติลูกค้าและเลือกตั๋วไถ่ถอนแล้ว
2. ตรวจว่าปุ่มจำนำสินค้าเดิมอีกครั้งกดได้
3. กดปุ่ม ตรวจว่ากลับหน้ารับจำนำใหม่พร้อมข้อมูลถูกต้อง

UAT กฎป้องกัน
1. ตั๋ว Active และ Sold ต้องกดปุ่มไม่ได้
2. ตั๋วเดิมที่มีตั๋วใหม่แล้วต้องใช้ซ้ำไม่ได้
3. ทดลอง IMEI / Serial ที่ซ้ำกับตั๋ว Active ต้องถูกปฏิเสธ
4. ตรวจตั๋วเดิมว่ายังคงสถานะไถ่ถอนและประวัติเดิมครบ
5. ตรวจ Dashboard และรายการวันนี้ว่าตั๋วใหม่ถูกนับเป็นรายการจำนำใหม่ตามปกติ
