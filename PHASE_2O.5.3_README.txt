ManaChaiLeasing Phase 2O.5.3
Pawn Date Segment Selection and ESC Close
Version 0.3.9

สิ่งที่ปรับปรุง
1. ช่อง "วันที่รับจำนำ" ในหน้ารับจำนำใหม่
   - คลิกเลขวัน ระบบเลือกเลขวันทั้งส่วน
   - พิมพ์เลขใหม่ทับค่าเดิมได้ทันทีโดยไม่ต้องลบก่อน
   - กดลูกศรขวาเพื่อเลือกเดือน และกดอีกครั้งเพื่อเลือกปี
   - กดลูกศรซ้ายเพื่อย้อนกลับจากปีไปเดือนและวัน
   - การกดปุ่มปฏิทินยังเปิดปฏิทินได้ตามเดิม

2. หน้ารายละเอียดตั๋วจำนำ
   - กด ESC เพื่อปิดหน้าต่างได้
   - ปุ่ม "ปิด" และปุ่มดำเนินการอื่นยังทำงานเหมือนเดิม

Version และ Database
- ยังคงเป็น 0.3.9 เพราะเป็น UAT Hotfix ของ Phase 2O.5
- ไม่มี Database Migration เพิ่ม
- ไม่แก้ไขข้อมูลตั๋วหรือ Transaction

UAT ช่องวันที่รับจำนำ
1. เปิดหน้ารับจำนำใหม่ ตรวจว่าวันที่เริ่มต้นเป็นวันนี้
2. คลิกตรงเลขวัน ตรวจว่าเลขวันถูกเลือกทั้งส่วน
3. พิมพ์วันใหม่ ตรวจว่าค่าใหม่แทนค่าเดิมโดยไม่ต้องกดลบ
4. คลิกวัน แล้วกดลูกศรขวา ตรวจว่าเลือกเดือน
5. กดลูกศรขวาอีกครั้ง ตรวจว่าเลือกปี
6. กดลูกศรซ้าย ตรวจว่าย้อนกลับไปเดือนและวันได้
7. กดปุ่มปฏิทินและเลือกวัน ตรวจว่ายังทำงานตามเดิม
8. บันทึกตั๋วและตรวจวันที่ในรายละเอียดตั๋ว

UAT หน้ารายละเอียดตั๋ว
1. ดับเบิลคลิกรายการเพื่อเปิดหน้ารายละเอียด
2. กด ESC ตรวจว่าหน้าต่างปิด
3. เปิดอีกครั้งและกดปุ่ม "ปิด" ตรวจว่ายังปิดได้
4. ตรวจว่าปุ่มต่อดอก ไถ่ถอน จำหน่าย และแก้ไขข้อมูลยังทำงานตามเดิม
