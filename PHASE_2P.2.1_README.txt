ManaChaiLeasing — Phase 2P.2.1 Controlled Sale Correction
Version 0.4.4

ขอบเขต
- เพิ่มการแก้ไขข้อมูลการขายสำหรับรายการซื้อขายสถานะ "ขายแล้ว"
- เปิดได้จากปุ่ม "ขาย / แก้ไขการขาย" ในตารางรายการซื้อขาย
- เปิดได้จากปุ่ม "แก้ไขข้อมูลการขาย" ในหน้ารายละเอียดรายการขายแล้ว
- รายการสถานะรอขายยังใช้หน้าจอเดียวกันเพื่อบันทึกขายใหม่ตามเดิม

ข้อมูลที่แก้ไขได้
- วันที่ขาย
- ราคาขาย
- ช่องทางการรับเงิน
- หมายเหตุการขาย
- เหตุผลการแก้ไขเป็นช่องไม่บังคับ
- หากเว้นเหตุผล ระบบบันทึกใน Audit Log ว่า "ไม่ได้ระบุ"

หลักการบันทึก
- อัปเดต DirectPurchaseTransaction ชนิด Sale เดิม ไม่สร้าง Transaction ขายซ้ำ
- รักษาเวลาเดิมของ Transaction เมื่อเปลี่ยนวันที่ขาย
- วันที่ขายต้องไม่ก่อนวันที่รับซื้อและไม่เกินวันนี้
- หากไม่มีข้อมูลเปลี่ยนแปลง ระบบจะไม่บันทึก Audit Log เปล่า
- สถานะยังคงเป็น "ขายแล้ว" และข้อมูลการรับซื้อยังเป็นแบบอ่านอย่างเดียว
- ทำ Auto Backup หลังแก้ไขสำเร็จ

ผลต่อรายงาน
- ราคาขายใหม่ปรับยอดรับเข้า ยอดสุทธิ และกำไร/ขาดทุนทันที
- หากเปลี่ยนวันที่ขาย รายการจะย้ายไปอยู่ในสรุปของวันที่ใหม่
- ตารางรายการซื้อขายและหน้ารายละเอียดแสดงข้อมูลล่าสุด
- Audit Log เก็บค่าเดิม ค่าใหม่ ผู้ใช้ เครื่อง วันเวลา และเหตุผล

ฐานข้อมูล
- ไม่มี Migration เพิ่ม
- ใช้ Transaction และ Audit Log จาก Phase 2P.1 เดิม

UAT แนะนำ
1. Build และเปิดโปรแกรม ตรวจ Version v0.4.4
2. เปิดรายการสถานะขายแล้วจากตาราง แล้วกด "ขาย / แก้ไขการขาย"
3. ตรวจว่าฟอร์มโหลดวันที่ ราคา ช่องทางรับเงิน และหมายเหตุเดิมครบ
4. แก้เฉพาะราคาขายโดยไม่กรอกเหตุผล ต้องบันทึกได้
5. ตรวจราคาขาย กำไร/ขาดทุน ตารางรายการซื้อขาย และหน้ารายละเอียดว่าปรับทันที
6. ตรวจหน้าหลักและรายการวันนี้ว่ายอดรับเข้า ยอดสุทธิ และกำไรตรงกับราคาใหม่
7. แก้วันที่ขาย ตรวจว่ารายการย้ายจากวันเดิมไปวันใหม่และไม่เกิดยอดขายซ้ำ
8. ทดลองวันที่ขายก่อนวันที่รับซื้อและวันที่อนาคต ต้องบันทึกไม่ได้
9. กดบันทึกโดยไม่เปลี่ยนข้อมูล ต้องแจ้งว่าไม่มีข้อมูลการขายที่เปลี่ยนแปลง
10. เปิดจากหน้ารายละเอียดรายการขายแล้ว แล้วกด "แก้ไขข้อมูลการขาย" ต้องทำงานเหมือนกัน
11. ตรวจว่าข้อมูลการรับซื้อยังแก้ไขไม่ได้และสถานะยังเป็นขายแล้ว
12. ทดสอบรายการรอขายใหม่ว่ายังบันทึกขายได้ตาม Phase 2P.2
