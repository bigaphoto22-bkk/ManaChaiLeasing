ManaChaiLeasing — Phase 2P.1.1 Direct Purchase Form UAT Hotfix
Version 0.4.1

รายการปรับปรุงจาก UAT Phase 2P.1

1. ปฏิทินวันที่รับซื้อ
- ขยาย Calendar Popup เป็นขนาดเดียวกับหน้ารับจำนำใหม่
- ใช้ Scale 1.55 เพื่อให้ตัวเลขวันและปุ่มเปลี่ยนเดือนอ่านและกดง่ายขึ้น
- รองรับการเลือกส่วนวัน / เดือน / ปีด้วยเมาส์และปุ่มลูกศรเหมือนหน้ารับจำนำ

2. แบบฟอร์มข้อมูลสินค้า
- เปลี่ยนจากช่องข้อมูลรวมเป็นฟอร์มแยกตามประเภทเดียวกับหน้ารับจำนำใหม่
- โทรศัพท์มือถือ / Tablet: ยี่ห้อ รุ่น ความจุ สี IMEI อุปกรณ์ สภาพ/ตำหนิ
- อุปกรณ์ IT: ชนิดสินค้า ยี่ห้อ รุ่น สเปก Serial อุปกรณ์ สภาพ/ตำหนิ
- เครื่องใช้ไฟฟ้า: ชนิดสินค้า ยี่ห้อ รุ่น ขนาด/ความจุ Serial อุปกรณ์ สภาพ/ตำหนิ
- อื่น ๆ: ชนิดสินค้า ยี่ห้อ รุ่น รายละเอียด Serial อุปกรณ์ สภาพ/ตำหนิ
- Dropdown สามารถเลือกค่าที่มีอยู่หรือพิมพ์ค่าใหม่ได้
- สรุปรายละเอียดสินค้าสร้างอัตโนมัติตามประเภทสินค้า

3. Smart Dropdown ร่วมกัน
- โหลดค่าที่ระบบเคยเรียนรู้จากหน้ารับจำนำมาแสดงในหน้ารับซื้อ
- ค่าที่พิมพ์ใหม่ในหน้ารับซื้อจะถูกบันทึกลง Smart Lookup ชุดเดียวกัน
- ยี่ห้อ รุ่น ความจุ สี และชนิดสินค้าจึงใช้งานต่อกันได้ทั้งสองหน้า

4. การแก้ไขรายการเดิม
- รายการรับซื้อที่มีอยู่เดิมจะถูกแปลงกลับเข้าแบบฟอร์มตามประเภทสินค้า
- ยังแก้ไขรายละเอียดได้เฉพาะสถานะรอขาย
- Audit Log, สถานะ, Transaction และยอดเงินสดทำงานเหมือน Phase 2P.1

ฐานข้อมูล
- ไม่มี Migration เพิ่ม
- ใช้โครงสร้างฐานข้อมูล Phase 2P.1 เดิม

UAT แนะนำ
1. Build และเปิดโปรแกรม ตรวจ Version v0.4.1
2. เปิด รายการซื้อขาย > รับซื้อสินค้าใหม่
3. เปิดปฏิทินวันที่รับซื้อ ตรวจว่ามีขนาดเท่าหน้ารับจำนำใหม่
4. เปลี่ยนประเภทสินค้าครบทั้ง 4 ประเภท ตรวจว่าฟอร์มสลับถูกต้อง
5. โทรศัพท์: ทดลองเลือกและพิมพ์ใหม่ในยี่ห้อ รุ่น ความจุ และสี
6. IT และเครื่องใช้ไฟฟ้า: ทดลอง Dropdown ชนิดสินค้า ยี่ห้อ และรุ่น
7. ตรวจว่าสรุปรายละเอียดสินค้าเปลี่ยนทันทีตามข้อมูลที่กรอก
8. บันทึก แล้วเปิดรายการเดิมกลับมาแก้ไข ตรวจว่าข้อมูลลงช่องถูกต้อง
9. เปิดหน้ารับจำนำใหม่ ตรวจว่าค่า Dropdown ใหม่จากหน้ารับซื้อถูกนำมาใช้ร่วมกัน
10. ตรวจยอดจ่ายออก รายการวันนี้ การยกเลิก และ Audit Log ว่ายังทำงานเหมือนเดิม
